# rc.12 · 协同格式刷

本版新增格式刷，其他功能边界沿用 rc.11。schema 仍为 4，不切换 epoch、不重建已有 schema 4 基线。schema 1/2/3 的协同格式刷不开放，不能通过改写旧基线版本绕过。

## 用法与语义

- 选中源区域，单击顶部“格式刷”，再点击/拖选目标，应用一次后退出。
- 双击“格式刷”进入连续模式；再次单击或 Esc 取消。切为只读自动取消，实际应用再次检查权限、就绪和编辑状态。
- 取样、模式切换、源框绘制和取消均为当前页面临时状态，零正文提交。一次实际应用最多产生一个本地样式事务，无变化不产生 Yjs 更新。
- 源为多格时按矩阵重复铺到目标；目标是单格时按源尺寸展开。每次取样/应用最多 10000 格，超范围明确拒绝，不自动扩展轴。
- 复制字体、字号、整格文字样式、文字/填充色、边框、对齐、换行、数字格式。目标旧样式中源未包含的属性会清除；空白默认格式源可清除目标整格格式。
- **不复制内容或合并结构**，不复制条件格式/验证规则、行高列宽、评论和权限。源单元格局部富文本 runs 不作为格式刷样本；目标已有局部样式和原子对象原样保留，局部显式样式可能覆盖刷入的整格默认字体样式。这不是字符区间格式刷。
- 样式按既有完整样式寄存器并发裁决，与内容寄存器分离；不同会话编辑目标文字不会被格式刷覆盖。撤销仅处理本会话操作，不能覆盖后来的远端获胜样式。

## 正式接入

包自带工具栏及原生格式刷入口使用同一实现，宿主不补 Univer 内部事件。

`session.capabilities.formatPainter` 提供 `supported/enabled/code/reason`。可通过已导出的 `SpreadsheetFormatPainter` 类型和 `handle.getRuntime()?.formatPainter` 调用 `start(continuous?)`、`cancel()`、`getMode()`、`subscribe(listener)`。`setGuard` 供包内 runtime 接入，不应由宿主覆盖权限检查；平台服务端仍承担最终 ACL。自定义 runtime 若不实现该接口，双行工具栏保持禁用。

## 验证

`formatPainter.test.ts`：模式对应样式矩阵构建、旧属性清除、重复/单点展开、越界/规模限制；真实 Univer mutation → 两会话零回声、一次提交、公式与用户身份保留、撤销重做、后来远端样式不被撤销覆盖、checkpoint/压缩恢复、只读防写。

`capabilities.test.ts`：格式刷的 supported/readonly/not-ready、原生命令映射。

真实浏览器安装产物验收与唯一安装包哈希记录在工作区 `artifacts/format-painter/`；构建或模型测试不代表生产 Doca ACK/outbox/reconnect 已联合验收。
