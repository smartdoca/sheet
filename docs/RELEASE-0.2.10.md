# 0.2.10 原生卸载与弹窗焦点

关闭历史表格预览时，Univer 0.25.1 验证提示对悬停位置的 100ms debounce 会在流完成时立即刷新最后一个位置；此时工作簿可能已移除，导致 `null.getSheetBySheetId`。默认运行时现在先通过原生悬停失效操作清空位置，再执行销毁。快速卸载还暴露原生自动行高服务遗留的 idle 回调，本版在其渲染服务销毁时取消回调并释放待处理骨架。

链接弹窗准备好原生草稿后，原生编辑器仍可能通过延迟重试、activate、sync 或选区更新抢回焦点，使显示文字或 URL 实际进入单元格草稿。本版在原生文本服务实例上管理临时弹窗焦点控制权，覆盖以上入口；显式焦点交回、插入、取消、权限撤销和卸载按生命周期释放，不用等待或反复填充来掩盖问题。文档选择器沿用同一控制权。

业务单元格覆盖层同时增加活动运行时检查与工作簿空值防护，取消旧帧和命令监听。公开 API、exports、数据格式、Yjs schema、epoch、checkpoint 和已有文档均不改变。model、Yjs 与 XLSX 六个 ESM/CJS 运行时文件与 0.2.9 逐字节一致；公开声明等价，构建产物仅有联合类型成员顺序及引用哈希变化。

隔离 Chrome 使用实际 0.2.9 包重现悬停卸载和焦点抢占；冻结的 0.2.10 候选在全新消费目录通过十轮待处理悬停后立即卸载、同容器切换、原生 focus/activate/sync 期间弹窗键入、取消及原生草稿继续输入。双页通过取消/关闭/Esc/外部关闭、链接与文档插入、远端无回声、撤销重做、checkpoint 恢复和只读。90 秒空闲零内容写入，浏览器错误与警告为空。TypeScript、四入口 ESM/CJS/DTS 构建及 157 项测试通过，原有一项可选性能测试跳过。测试只用隔离数据，原失败记录保留。
