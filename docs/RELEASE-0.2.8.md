# 0.2.8 剪贴板拒绝提示与剪切重试

复制后粘贴到已有行列范围以外时，Univer 会先执行原生行列插入。协同会话拒绝这些没有稳定身份的结构写入，但此前提示错误地使用了功能的能力说明，显示“稳定行列身份……A1 公式引用跟随”。现在明确提示先插入足够行列，再重新粘贴，停留时间为五秒。这里保留现有扩表规则，没有放开原生结构写入。

原生引擎在粘贴失败后仍会清空剪切缓存。包内现在仅在粘贴失败、没有应用内容写入且缓存确实已被消耗时恢复该缓存，覆盖普通粘贴、快捷键及内部缓存粘贴入口。用户可以换到有效位置重试，源内容不会被提前删除。

隔离 Chrome 双页使用实际 tgz 的运行时代码验证了普通复制、越界剪切拒绝且零内容提交、换位置重试、整次剪切撤销/重做及 checkpoint 刷新恢复。另用合成图片验证跨客户端复制保留原文字和稳定资源 ID，只读粘贴由原生权限弹窗阻止。TypeScript、四入口 ESM/CJS/DTS 构建及 152 项测试通过，原有一项可选性能测试跳过。

公开 API、exports、依赖、文档格式和协同 schema 不变；model、Yjs 和 XLSX 的六个运行时文件与 0.2.7 逐字节相同。未编辑用户文档，未修改 Doca 工作区。此前 `sheet.mutation.re-calc-filter` 的恢复顺序修复保留，真实 Univer 筛选会话回归测试通过。
