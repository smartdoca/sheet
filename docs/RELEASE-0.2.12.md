# 0.2.12 筛选范围持久化修复

遵循已批准的筛选范围规则：打开工作簿保留原范围；确认有效筛选条件时，在原列边界内扩展到最后一条有内容的记录；紧邻追加内容时扩展到连续记录末尾。取消、清除条件、纯样式和范围外列内容不会扩展范围。

追加内容与范围扩展进入同一 Yjs 事务和撤销步骤。远端投影和 checkpoint 恢复先应用已保存范围，再计算隐藏行，不产生本地回声。公开 exports、类型和依赖保持不变；schema 6、baseline、epoch、checkpoint 和原更新格式不变。既有历史读取及默认尺寸规则不变，没有数据转换或自动迁移。回退保留新保存范围和后续内容；上一包可读取原生范围，但不会持久化后续隐式扩展。

发布前 TypeScript、ESM/CJS/DTS 构建及 src 测试通过：171 项通过、1 项既有性能测试按配置跳过。此前编译包双页浏览器验收覆盖确认、原生粘贴、单步撤销/重做、无回声、checkpoint 刷新和 137 秒空闲；具体边界见 Doca 的筛选范围验收记录。本地默认测试命令还扫描了 artifacts 内旧故障复现，该复现预期旧故障仍存在，因此以受版本控制的 src 测试为发布门槛，保留原日志。

生成日志及归档位于 artifacts/verification/release-0.2.12/。不使用用户文档或数据库。
