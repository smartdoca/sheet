## 共享冻结

“锁定到行首/列首”指滚动冻结，不是编辑权限锁定。用户已确认冻结是共享文档设置。

- `SpreadsheetEditorHandle.setFreeze({ rows, columns })`：从首行/首列冻结指定数量；0 表示该轴取消冻结。必须保留至少一个可滚动行/列。工具栏提供首行、首列、两者、当前单元格之前和取消冻结。
- 正式会话新增 **显式 opt-in schemaVersion 2**，codec 仍为 `exlsx-cell-registers`。`createExlsxBaseline(snapshot, epochId, { schemaVersion: 2 })` 创建新谱系；默认仍为 schema 1。两者不可混合恢复，运行中的旧文档不自动升级、不清空待确认更新。
- 平台必须先协调旧客户端与待确认队列；不能在同一活动 epoch 上更改 schema。没有实现自动在线升级协议。此变更不表示已实现结构协同。
- schema 2 在 `exlsx:sheet-state` 中按稳定工作表 ID 保存冻结状态；行列边界使用固定轴的稳定 `b:index` 身份。当前轴插删/重排仍禁止，不宣称已解决结构变化后的冻结与引用映射。
- 同一工作表的冻结设置是一个原子寄存器，采用 Yjs 确定性最后写入裁决；同时修改两轴不做字段级合并。撤销只跟踪本会话，不能覆盖后来接收到的远端修改。
- `session.capabilities.freeze` 是当前会话的入口判定；schema 1 不启用。只读会显示共享冻结，但不得修改。
- 本地冻结走既有本地事务及平台 outbox；远端投影、初始化、滚动不产生新提交。没有新增连接、保存接口或 ACK 通道。
- `checkpoint()`、`compactExlsxRecovery()` 不改变 epoch；Node `projectExlsxWorkbook()` 恢复冻结。独立副本保留 schema 并创建新 epoch。

## 原生编辑与工具栏

| 能力 | 当前状态与边界 |
| --- | --- |
| 单元格内局部字体样式 | 已接原生文本选区命令，修复工具栏失焦及整格覆盖草稿问题；预设颜色可用于编辑态，自定义颜色输入在编辑态禁用 |
| Shift+Enter 多行 | 已接原生换段命令；公式编辑不走此快捷键 |
| 多行自动高度 | 本地与远端内容变化触发分批原生测量；`ah` 是派生缓存，不作为正文提交；手动行高 `h/ia` 未因此开放 |
| @ 与普通链接实验 | `getNativeText()` 提供状态、范围捕获、原子/链接插入、节点事件；宿主 demo 提供用户查询与卡片，无包内用户接口 |
| 稳定身份 | 原子节点保存 `type/refId/label`，label 仅展示回退；同格仍是寄存器冲突，不是字符级 CRDT |
| 任意自定义内联外观、图片/附件 | 未完成；现有原子范围采用原生文字渲染，不能当作任意 React/图片内联渲染能力 |
| 原子剪贴板、真实中文输入法、公式栏往返 | 尚未完成完整浏览器验收；不宣称全面支持 |
| 筛选、排序、合并、行列结构 | 正式协同尚未实现，入口维持禁用并说明原因；不能仅开放底层菜单 |
| 冻结 | 上述 schema 2 的首行首列、双页同步、撤销重做、checkpoint 恢复及只读已通过安装包浏览器回归；完整缩放组合仍待测 |
| 全集 demo | 未完成。当前为隔离的原生混排实验，不是全集交付 |
