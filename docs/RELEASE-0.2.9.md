# 0.2.9 下拉列表删除键

在网格选中下拉单元格后按 Delete / 退格，之前只清空了所选值，验证规则仍在，因此留下空白控件。现在通过原生快捷键优先级调用验证规则移除命令，仅移除选区中的单选/多选列表，保留已有值和样式；共享规则在选区外的部分及其他验证类型保留。混合选区中只要包含下拉列表，此操作优先移除下拉，不清空其他单元格内容。

无下拉的单元格仍走原生清空内容。文本草稿、公式栏、弹窗输入框及其他组件继续拥有各自的删除键；Shift 等组合键不改变。原生工作簿、工作表和范围编辑权限在执行时重新检查。规则删除与局部范围更新沿用现有原生命令和协同投影，公开 API、持久化字段、schema、epoch、checkpoint 和已有规则格式均不变。

直接声明固定版本 `@univerjs/sheets-data-validation@0.25.1`，与现有锁文件的传递版本一致，避免打包适配器时嵌入第二份原生服务。model、Yjs 和 XLSX 入口运行时代码不变。

隔离 Chrome 对照实际 0.2.8 tgz 重现“值被清空、控件仍在”。实际 0.2.9 tgz 双页通过删除键、退格键、局部共享规则、值和加粗样式保留、撤销重做、普通单元格清空、原生文字及弹窗退格、只读保护和 checkpoint 重载；公式栏退格另行验证。93 秒空闲两端零内容提交，浏览器错误与警告为空。TypeScript、四入口 ESM/CJS/DTS 构建和 154 项测试通过，原有一项可选性能测试跳过。公开声明、exports 及 model/Yjs/XLSX 六个运行时文件与 0.2.8 逐字节一致。
