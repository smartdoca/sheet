# 0.2.15 工具栏文字点击与冻结单元格编辑修复

双行工具栏的“换行”“合并”文字现在位于原生按钮内部，点击图标、文字和按钮间隙执行相同动作；窄屏折叠菜单也使用同一按钮。保留原生选区、焦点、只读和编辑中禁用规则，没有新增事件代理或宿主绑定。

Univer 0.25.1 在开始单元格编辑时，按冻结行列数量减索引来滚动；冻结行高 180、普通行高 30 时，会把可滚动区顶部的目标向上移 150px，遮在冻结行下面。现在在原生单格 scroll-to-range 完成后、草稿定位之前，根据骨架累计行高/列宽和实际偏移，校正被遮挡的轴。隐藏尺寸自然计入累计值，50%/100%/150% 使用同一原生坐标计算。已可见、冻结区内、无冻结及多格导航保留原生行为；监听随默认运行时释放。

修复不改变单元格内容、尺寸、选区、撤销或保存语义，不新增网络、存储或兼容适配。公开 API、exports、依赖和 CSS 保持 0.2.14；model/yjs/preferences/xlsx 八个 JS 运行时逐字节一致。schema 6、永久锚点、baseline、epoch、checkpoint、pending 更新、既有历史读取和默认尺寸规则保持不变。

177 项源码测试通过，1 项既有可选性能测试跳过；TypeScript 与五入口 ESM/CJS/DTS 构建通过。实际打包运行时完成 16 组尺寸/冻结/缩放场景，覆盖 48 次双击、F2、直接键入和 48 次只读阻止检查，草稿可继续输入并取消，零共享写入且不重建编辑器。隐藏行列 150% 场景空闲 157.981 秒仍为零写入，卸载和控制台检查通过。双页验收覆盖文字换行、保留内容的合并、窄屏、只读、正常输入及各自撤销/重做，远端无回声。正式包回下载记录位于 `artifacts/verification/release-0.2.15/`。

宿主升级官方 npm `@smartdoca/sheet@0.2.15` 后重新构建即可，无新增 props 或宿主滚动补丁。本次不修改 Doca 源码、依赖或锁文件；编译 Doca 的最终集成由宿主任务完成。Safari/Firefox 未验收。默认测试命令会扫描 ignored artifacts 中预期旧筛选故障存在的历史复现，发布门槛沿用受版本控制的 `src` 测试。
